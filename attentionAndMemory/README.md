### fonctionnement du dépôt :
## lancement des jeux :
- Lancer le script app.py puis suivre l'url indiquée dans le terminal.

## machine learning :

# ML_eeg.ipynb
- lance l'apprentissage avec des données ajustables
- spécifier les noms Revillon, Kayssieh, ... pour choisir les data d'entraînement et de test

# splitSignal.py
- contrairement à ce qu'indique son nom, ce fichier ne traite pas le signal mais s'occupe de nettoyer les données venant de la base de donnée contenue dans le dossier "instance", celles qui sont erronées et de renvoyer des temps de réactions et des instants de clics.

# signalTreatment.py
- ce fichier fait le préprocessing des signaux

# dataSorting.py
- ce fichier fait la labellisation des données
